# 신화 메신저 모바일 설치

관리자들이 설치 파일을 내려받아 직접 설치하는 공개 배포 공간입니다. 앱 소스 저장소는 별도로 관리합니다. App Store·Google Play에 등록하지 않습니다.

| 운영체제 | 설치 파일 | 현재 상태 | 설치 방법 |
|---|---|---|---|
| Android | [서명된 APK 다운로드](https://github.com/DevSaerongcho/Shinhwa-Messenger-Mobile-Releases/releases/download/mobile-v0.17.3-preview.1/Shinhwa-Messenger-0.17.3-Android-preview.apk) | 0.17.3 기준 기술 시험판 | [Android 설치 안내](INSTALL-ANDROID.md) |
| iPhone·iPad | 아직 제공하지 않음 | Apple 팀 서명·기기 등록 확인 중 | [iPhone 설치 안내](INSTALL-IOS.md) |

[설치 파일과 SHA-256 검증 파일](https://github.com/DevSaerongcho/Shinhwa-Messenger-Mobile-Releases/releases/tag/mobile-v0.17.3-preview.1)

현재 Android 파일은 **운영용 기능 검증을 마친 정식판이 아닙니다.** 실제 Microsoft 로그인·기기별 전체 기능·백그라운드 푸시 검증과 운영 서버의 모바일 지원 코드 적용이 남아 있습니다. 관리자 시험 설치용으로 제공합니다.

최소 실행 범위는 Android 7 이상 및 최신 시스템 WebView이며, iOS 프로젝트의 최소 대상은 iOS 15입니다. 최신 갤럭시·iPhone Duo를 포함한 모든 기종 검증 완료를 의미하지 않습니다. 모바일 접속에는 기존 Tailscale 연결, 승인된 관리자 계정 및 서버 이용 권한이 필요합니다. 설치만으로 관리자 권한이 생기지 않습니다.

채팅·업무와 관리자·인게임·프로젝트·고객센터 47개 운영 화면을 포함하는 0.17.3 소스를 기준으로 준비했습니다. 전체 기능의 실제 동작 검증은 진행 중입니다. iPhone 설치 파일은 사용할 수 있는 서명된 IPA가 준비되면 이곳에 추가합니다.
